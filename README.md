# Komeza Manasse | Portfolio

A one-page portfolio for a data analyst based in Kigali, Rwanda. It covers ETL pipelines, dashboards and LLM-assisted analysis on WHO data.

- Plain HTML and CSS in a single file (`index.html`), no build step
- Fonts load from Google Fonts
- Light and dark mode follow the visitor's system setting

Open `index.html` in a browser to view it locally.
